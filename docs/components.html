05 / Cards

Cards share one grid and one set of lines

The grid has a 1px gap over a background in the border colour, and that gap is the border you see. The cards have no borders of their own, so lines never double up or drift out of line.

08 / Menus

Menus, submenus and context menus look the same

All three use a raised surface, a heavy 1px border and a hard 2px shadow. A submenu sits flush against its parent, so the two borders look like one line. Arrow keys move between items, → opens a submenu, ← closes it, and typing a letter jumps to the matching item.

11 / Accordion

Accordions built on native disclosure

It's built on <details>, so it works without JavaScript and the browser's find-in-page can open a matching item. Give the items the same name and only one can be open at a time.

Exclusive: one open at a time

01What counts as a build minute?

Wall-clock time from the first build step to the upload finishing, rounded up to the next minute per build.

02Can I bring my own domain?

Yes, on every plan. Point a CNAME at edge.orbit.app; certificates are issued automatically.

03What happens when I hit a limit?

Nothing stops. You get an email at 80% and 100%, and overage is billed at the published rate.

12 / Code

Inline, block, numbered, diff and terminal

Each line is its own span.ln, so line numbers, highlights and diff marks belong to the line instead of sitting on top of it. The copy button copies the code without the line numbers.

Inline code sits in a sunken box with a subtle rule: run orbit deploy --prod, then check ORBIT_TOKEN is set. Keys use Ctrl K, and a match shows up as an inverted inline block instead of a highlighter.

20 / Agent & chat

Agent chat reads like a transcript

There are no chat bubbles. Tool calls look like log lines, with status, name, arguments and duration, and expand to show their input and output. Reasoning is collapsed and muted. An approval is the only point where the agent waits for a person. You can type in the composer below.

21 / Combobox & multi-select

Type to filter, arrows to move, Enter to take

Focus stays in the input the whole time, and the highlighted option is tracked with aria-activedescendant. The part of each option that matches what you typed is shown inverted. The divider is just the line

24 / Editable data grid

It works like a spreadsheet

Arrow keys move the selection ring. Enter, F2, a double-click or just typing starts an edit. Enter saves and moves down, Tab moves right, and Esc cancels. Edited cells get an accent corner, and the region column checks what you type.

25 / Colour picker

A colour picker that tells you the contrast

It has a saturation and brightness field, a hue strip, a hex input and swatches. The readout also checks the colour against the page background. Picking a blue is only half the job. You also need to know whether text is readable on it.

On canvas

Drag in the field or use the arrow keys on it; the hue strip is a native range input. The eyedropper button appears only where the browser supports it.

26 / Notification inbox

Unread items get a mark instead of a tint

The count on the bell uses the accent colour, because it's the one thing in the bar that needs attention. Unread items get a 6px accent square and full-strength text. Read items are muted. You can act on an item without opening it.

27 / Blueprint details

Off by default, and no more than three per screen

Put these everywhere and they turn into clutter. They work best on hero sections, feature panels and empty states.

Grid substrate

8px squares at 5.5% ink. Element edges should line up with it.

Corner ticks

Registration marks

Mark two corners by default, and leave most cards without them.

Hatch fill

For placeholders and inactive areas. Boxy's version of the gray placeholder box.

Technical annotations

Small mono metadata is the easiest way to make a page look like a datasheet. Only use it for real values.
