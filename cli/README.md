# boxy-design

CLI installer for [Boxy](https://github.avestura.dev/boxy-design-skill/) — a
sharp-edged, zero-radius design system for AI coding agents.

```bash
npx boxy-design init              # Claude Code
npx boxy-design init --ai all     # + Cursor, Windsurf, AGENTS.md, Copilot
npx boxy-design check "src/**/*"  # lint against the system
```

Full documentation: <https://github.com/avestura/boxy-design-skill>
